# Raw Data Storage

This directory contains large source files managed with Git LFS.

## File Categories
- Telegram media (images, videos)
- PDF documents
- GIS data files
- CSV databases

## Access Requirements
- Git LFS must be installed
- Appropriate credentials for pulling large files
- Sufficient storage space (~XX GB)

## Forensic Integrity
All files maintain:
- SHA-256 hashes
- Original timestamps
- Source attribution
- Chain of custody documentation
